# PRISM Health Timeline

The timeline is a projection over evidence, not a second source of truth.

Timeline events reference evidence and resources.

Each event contains:

- event date or date range
- event type
- care pathway
- verification status
- evidence IDs
- resource IDs

This allows a patient to open a timeline event and navigate back to the exact source document, ABDM resource or patient-reported intake from which it originated.
