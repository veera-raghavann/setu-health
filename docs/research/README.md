# Research Tracks

SETU currently has three immediate research tracks feeding PRISM.

## OCR

Goal: identify and benchmark OCR/document-understanding approaches for Indian medical documents, including printed and handwritten prescriptions and reports.

Deliverables:
- candidate models/services
- supported languages/scripts
- handwriting performance
- field/entity extraction accuracy
- confidence/provenance strategy
- latency/cost
- privacy/deployment constraints
- recommendation with benchmark evidence

## ASR / Bhashini

Goal: evaluate Indian-language speech recognition for noisy clinical environments, accents and code-switching.

Deliverables:
- supported languages
- ASR quality metrics
- clinical entity preservation
- latency
- offline/online options
- API/model constraints
- privacy and deployment considerations
- recommendation with benchmark evidence

## Flutter / React Native

Goal: select the patient-client technology based on accessibility, camera/document capture, audio, offline/degraded operation, deployment targets and maintainability.

Deliverables:
- capability matrix
- native integration requirements
- accessibility support
- performance
- ecosystem maturity
- deployment implications
- recommendation with evidence

Research notes must distinguish measured results from vendor claims and general assumptions.
