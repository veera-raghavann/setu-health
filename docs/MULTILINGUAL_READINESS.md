# PRISM Multilingual Readiness

Current prototype languages: English, Tamil, Hindi.

Language is carried across UI → voice hint → conversation → safety → next-question text → touch labels → OCR hint.

Before demo, validate typed and voice intake plus image/PDF OCR in all three languages. Test emergency phrases, record-upload intent and ABHA intent in each language.

A language is not considered supported merely because the first prompt is translated; the entire workflow must pass.
